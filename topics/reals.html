1. Зачем нужны вещественные числа: дыры в \(\mathbb{Q}\)

Рациональных чисел «много»: между любыми двумя есть третье. Но в них есть дыры. Число \(\sqrt{2}\) не рационально (доказательство — в теме «Логика»), а значит, на «рациональной прямой» на его месте пусто.

Последовательность \(1;\ 1{,}4;\ 1{,}41;\ 1{,}414;\ \ldots\) (десятичные приближения \(\sqrt{2}\)) состоит из рациональных чисел, её члены неограниченно сближаются друг с другом — но в \(\mathbb{Q}\) ей не к чему сходиться. Анализ на такой прямой невозможен: нельзя было бы доказать даже, что у уравнения \(x^2 = 2\) есть решение.

Почему у множества \(\{x \in \mathbb{Q} : x^2 < 2\}\) нет точной верхней грани в \(\mathbb{Q}\)?

Пусть рациональное \(s > 0\) — его точная верхняя грань. Так как \(s^2 \ne 2\) (\(\sqrt{2}\) иррационален), остаются два случая.

Если \(s^2 < 2\), то для малого рационального \(h > 0\) ещё \((s + h)^2 < 2\) — значит, \(s + h\) в множестве и \(s\) не верхняя граница. Если \(s^2 > 2\), то для малого \(h\) ещё \((s - h)^2 > 2\) — значит, \(s - h\) тоже верхняя граница, и \(s\) не наименьшая. Противоречие в обоих случаях.

2. Аксиома полноты

Вещественные числа задаются аксиомами: это поле (сложение, умножение и их свойства), упорядоченное (свойства \(\le\), согласованные с операциями), и в нём выполнена главная аксиома:

Аксиома полноты (непрерывности). Если \(A, B \subset \mathbb{R}\) непусты и любой элемент \(A\) не больше любого элемента \(B\), то найдётся число \(c\), разделяющее их:

\[ \begin{gathered} \forall a \in A \;\; \forall b \in B\colon\; a \le b \\ \Downarrow \\ \exists c \in \mathbb{R} \;\; \forall a \in A \;\; \forall b \in B\colon\; a \le c \le b. \end{gathered} \]

Смысл: на прямой нет дыр. В \(\mathbb{Q}\) аксиома не выполнена: для \(A = \{x > 0 : x^2 < 2\}\) и \(B = \{x > 0 : x^2 > 2\}\) разделяющее число \(\sqrt{2}\) не рационально.

Остальные аксиомы (поле и порядок)

Сложение и умножение: коммутативность, ассоциативность, нейтральные элементы 0 и 1, противоположный \(-a\), обратный \(a^{-1}\) при \(a \ne 0\), дистрибутивность \(a(b + c) = ab + ac\).

Порядок: для любых \(a, b\) верно \(a \le b\) или \(b \le a\); из \(a \le b\) и \(b \le a\) следует \(a = b\); транзитивность; \(a \le b \Rightarrow a + c \le b + c\); \(0 \le a,\ 0 \le b \Rightarrow 0 \le ab\).

Всем этим аксиомам, кроме полноты, удовлетворяет и \(\mathbb{Q}\). Вся разница между \(\mathbb{Q}\) и \(\mathbb{R}\) — в одной аксиоме полноты.

3. Верхние границы, sup и inf

Число \(M\) — верхняя граница множества \(A\), если \(\forall x \in A\colon x \le M\). Множество с верхней границей называется ограниченным сверху.

Точная верхняя грань \(\sup A\) (супремум) — наименьшая из верхних границ. Аналогично \(\inf A\) (инфимум) — наибольшая из нижних границ.

Рабочее определение (им пользуются в доказательствах):

\[ \begin{aligned} s = \sup A \iff\; &(1)\;\; \forall x \in A\colon\; x \le s, \\ &(2)\;\; \forall \varepsilon > 0 \;\; \exists x \in A\colon\; x > s - \varepsilon. \end{aligned} \]

Условие (1) говорит, что \(s\) — верхняя граница, (2) — что любое меньшее число \(s - \varepsilon\) уже не граница. Подвигайте \(\varepsilon\):

все верхние границы \((s - \varepsilon;\ s)\) ● элемент правее \(s - \varepsilon\)
Чем sup отличается от max?

Максимум — наибольший элемент, он обязан принадлежать множеству. Супремум может и не принадлежать: у \((0;\ 1)\) максимума нет, а \(\sup = 1\).

Если максимум есть, то он и есть супремум. Обратно: если \(\sup A \in A\), то это максимум.

А если множество не ограничено или пусто?

Для неограниченного сверху множества пишут \(\sup A = +\infty\) (снизу — \(\inf A = -\infty\)). Это соглашение в расширенной прямой \(\overline{\mathbb{R}} = \mathbb{R} \cup \{-\infty, +\infty\}\). Для пустого множества по соглашению \(\sup \varnothing = -\infty\), \(\inf \varnothing = +\infty\): любое число является его верхней границей.

Как построить отрицание рабочего определения sup, разобрано по шагам в теме «Логика».

4. Теорема о существовании точной грани

Теорема. У любого непустого ограниченного сверху множества \(A \subset \mathbb{R}\) есть точная верхняя грань.

  1. \[ B = \{ M \in \mathbb{R} : M \text{ — верхняя граница } A \} \ne \varnothing \]
    Соберём все верхние границы в множество \(B\). Оно непусто, потому что \(A\) ограничено сверху.
  2. \[ \forall a \in A \;\; \forall M \in B\colon\; a \le M \]
    Это просто определение верхней границы: каждый элемент \(A\) не больше каждого элемента \(B\).
  3. \[ \exists c\colon\; a \le c \le M \quad \forall a \in A,\ \forall M \in B \]
    Условия аксиомы полноты выполнены — она даёт разделяющее число \(c\).
  4. \[ c \in B \quad \text{и} \quad c \le M \;\; \forall M \in B \]
    Левое неравенство \(a \le c\) значит, что \(c\) — верхняя граница. Правое \(c \le M\) — что она не больше любой другой. Значит, \(c\) — наименьшая верхняя граница: \(c = \sup A\). \(\blacksquare\)

5. Следствия аксиомы полноты

Принцип Архимеда

Множество натуральных чисел не ограничено сверху: \(\forall x \in \mathbb{R}\;\; \exists n \in \mathbb{N}\colon\; n > x\). Казалось бы, очевидно, но это следствие именно полноты.

  1. \[ \text{Пусть } \mathbb{N} \text{ ограничено сверху, } s = \sup \mathbb{N} \]
    От противного. Супремум существует по теореме из §4.
  2. \[ \exists n \in \mathbb{N}\colon\; n > s - 1 \]
    Условие (2) из рабочего определения sup с \(\varepsilon = 1\).
  3. \[ n + 1 > s, \quad n + 1 \in \mathbb{N} \qquad \text{— противоречие} \;\blacksquare \]
    Нашли натуральное число больше верхней границы \(s\) всех натуральных.

Следствие: \(\forall \varepsilon > 0\;\; \exists n\colon \frac{1}{n} < \varepsilon\) (возьмите \(n > \frac{1}{\varepsilon}\)). Именно поэтому \(\frac{1}{n} \to 0\).

Плотность \(\mathbb{Q}\): между любыми двумя числами есть рациональное

Пусть \(x < y\). По Архимеду выберем \(n > \frac{1}{y - x}\), то есть \(\frac{1}{n} < y - x\): «шаг» \(\frac{1}{n}\) меньше длины промежутка. Пусть \(m\) — наименьшее целое, большее \(nx\) (оно есть, опять по Архимеду). Тогда \(\frac{m - 1}{n} \le x < \frac{m}{n}\), и

\[ \frac{m}{n} \le x + \frac{1}{n} < x + (y - x) = y. \]

Итак, \(x < \frac{m}{n} < y\). \(\blacksquare\) Иррациональные числа тоже плотны: примените это к \(\frac{x}{\sqrt 2}\) и \(\frac{y}{\sqrt 2}\).

Существование \(\sqrt{2}\) в \(\mathbb{R}\)

Пусть \(s = \sup\{x > 0 : x^2 < 2\}\) — он существует (множество непусто и ограничено числом 2). Те же оценки, что в §1, показывают: \(s^2 < 2\) невозможно (\(s\) не был бы границей), \(s^2 > 2\) невозможно (\(s\) не был бы наименьшей границей). Значит, \(s^2 = 2\). В \(\mathbb{Q}\) этот аргумент ломается на первом шаге: супремума там нет.

Принцип вложенных отрезков (Кантор)

Если \([a_1; b_1] \supset [a_2; b_2] \supset \ldots\), то у всех отрезков есть общая точка. Если же длины \(b_n - a_n \to 0\), такая точка ровно одна.

Доказательство и почему важно, что это отрезки

Из вложенности \(a_n \le a_{n+k} \le b_{n+k} \le b_m\) для любых \(n, m\): каждый левый конец не больше каждого правого. Пусть \(c = \sup_n a_n\). Тогда \(a_n \le c\) (граница) и \(c \le b_m\) (так как каждое \(b_m\) — верхняя граница левых концов, а \(c\) — наименьшая). Значит, \(c \in [a_n; b_n]\) для всех \(n\). \(\blacksquare\)

Для интервалов утверждение неверно: \(\left(0;\ \frac{1}{n}\right)\) вложены, но общих точек нет (любое \(x > 0\) выпадает, когда \(\frac{1}{n} < x\)). Для \(\mathbb{Q}\) неверно и для отрезков: отрезки с рациональными концами, стягивающиеся к \(\sqrt{2}\), не имеют общей рациональной точки.

Эти факты — основа теорем Вейерштрасса и Больцано — Вейерштрасса в теме «Пределы», там же — верхний и нижний пределы.

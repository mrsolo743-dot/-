1. Монотонность и экстремумы

Из теоремы Лагранжа (тема «Производная»): если \(f' > 0\) на промежутке, функция там возрастает, если \(f' < 0\) — убывает. Значит, менять направление функция может только там, где \(f' = 0\) или \(f'\) не существует. Такие точки называют критическими.

Необходимое условие (Ферма): если \(x_0\) — точка экстремума и \(f'(x_0)\) существует, то \(f'(x_0) = 0\).

Достаточное условие 1 (смена знака): если \(f'\) при переходе через \(x_0\) меняет знак с «+» на «−», то это максимум; с «−» на «+» — минимум; если не меняет — экстремума нет.

Достаточное условие 2 (вторая производная): если \(f'(x_0) = 0\) и \(f''(x_0) > 0\), то это минимум; если \(f''(x_0) < 0\) — максимум.

Откуда условие со второй производной (и что делать, если \(f''(x_0) = 0\))

По формуле Тейлора при \(f'(x_0) = 0\):

\[ f(x) - f(x_0) = \frac{f''(x_0)}{2} (x - x_0)^2 + o\big((x - x_0)^2\big). \]

Рядом с \(x_0\) знак правой части определяется первым слагаемым. При \(f''(x_0) > 0\) разность положительна — значения больше, чем в \(x_0\): минимум.

Общий признак. Пусть первая ненулевая производная в \(x_0\) имеет порядок \(k\). Если \(k\) чётно, то это экстремум (минимум при \(f^{(k)}(x_0) > 0\)); если нечётно, экстремума нет. Например, у \(x^4\) в нуле \(k = 4\) — минимум, у \(x^3\) — \(k = 3\), экстремума нет.

Наибольшее и наименьшее значения на отрезке

По теореме Вейерштрасса они существуют, если \(f\) непрерывна на \([a;\ b]\). Достигаются они либо во внутренней точке — тогда это точка локального экстремума, то есть критическая, — либо на конце. Алгоритм: найти критические точки внутри отрезка, вычислить \(f\) в них и на концах и выбрать наибольшее и наименьшее из этих чисел. Дополнительно проверять, max это или min, не нужно.

2. Выпуклость и точки перегиба

Функция выпукла вниз (\(\cup\)) на промежутке, если любая её хорда лежит не ниже графика:

\[ f\big(t x_1 + (1 - t) x_2\big) \le t f(x_1) + (1 - t) f(x_2), \quad t \in [0;\ 1]. \]

Если неравенство обратное, функция выпукла вверх (\(\cap\)). Признак: \(f'' > 0 \Rightarrow \cup\), \(f'' < 0 \Rightarrow \cap\).

Точка перегиба — точка, где выпуклость меняется. Там \(f'' = 0\) или не существует, но этого мало: нужна смена знака \(f''\) (у \(x^4\) в нуле \(f'' = 0\), а перегиба нет).

Почему при \(f'' > 0\) график лежит над касательной

Формула Тейлора с остатком Лагранжа:

\[ f(x) = \underbrace{f(x_0) + f'(x_0)(x - x_0)}_{\text{касательная}} + \frac{f''(\xi)}{2}(x - x_0)^2. \]

Последнее слагаемое неотрицательно, значит, график не ниже касательной в любой точке \(x_0\). Это и есть выпуклость вниз (её эквивалентное описание: «график над всеми касательными»). \(\blacksquare\)

Бонус: неравенство Йенсена и среднее арифметическое

Для выпуклой вверх функции хорда лежит под графиком, и это обобщается на любое число точек: \(f\left(\frac{x_1 + \ldots + x_n}{n}\right) \ge \frac{f(x_1) + \ldots + f(x_n)}{n}\). Для \(f = \ln\) (\(f'' = -\frac{1}{x^2} < 0\)) получаем \(\ln \frac{x_1 + \ldots + x_n}{n} \ge \ln \sqrt[n]{x_1 \cdots x_n}\) — неравенство между средним арифметическим и средним геометрическим.

3. Асимптоты

Вертикальная \(x = c\): хотя бы один из односторонних пределов в \(c\) бесконечен. Искать её нужно в точках разрыва и на границах области определения.

Наклонная \(y = kx + b\) при \(x \to +\infty\) (или \(-\infty\)): \(f(x) - (kx + b) \to 0\). При \(k = 0\) асимптота горизонтальная.

\[ k = \lim_{x \to \infty} \frac{f(x)}{x}, \qquad b = \lim_{x \to \infty} \big(f(x) - kx\big). \]

Откуда формулы для \(k\) и \(b\)

Если \(f(x) = kx + b + \alpha(x)\) с \(\alpha \to 0\), то, разделив на \(x\), получаем \(\frac{f(x)}{x} = k + \frac{b}{x} + \frac{\alpha}{x} \to k\). Зная \(k\), находим \(b = \lim (f(x) - kx)\). Обратно: если оба предела существуют и конечны, то \(f(x) - kx - b \to 0\), то есть асимптота есть. Пределы при \(+\infty\) и \(-\infty\) считают отдельно — асимптоты могут быть разными (у \(\operatorname{arctg} x\): \(y = \pm\frac{\pi}{2}\)).

4. Схема полного исследования

  1. Область определения, точки разрыва.
  2. Чётность, нечётность, периодичность (если есть, исследуем половину).
  3. Нули и промежутки знакопостоянства.
  4. Асимптоты: вертикальные и наклонные.
  5. \(f'\): промежутки монотонности и экстремумы.
  6. \(f''\): промежутки выпуклости и точки перегиба.
  7. Сводная таблица и эскиз графика.

6. Приложения: оптимизация

Техника Самая экономная банка. Цилиндр объёма \(V\): площадь поверхности \(S(r) = 2\pi r^2 + \frac{2V}{r}\) (высота \(h = \frac{V}{\pi r^2}\)). Тогда \(S'(r) = 4\pi r - \frac{2V}{r^2} = 0\), откуда \(r^3 = \frac{V}{2\pi}\) и \(h = \frac{V}{\pi r^2} = 2r\). Самая экономная банка — та, у которой высота равна диаметру. \(S'' = 4\pi + \frac{4V}{r^3} > 0\), значит, это минимум.

Экономика Максимум прибыли. Прибыль \(\Pi(q) = R(q) - C(q)\) (выручка минус издержки). Условие \(\Pi'(q) = 0\) означает \(R'(q) = C'(q)\): предельная выручка равна предельным издержкам (MR = MC). Пример: \(R = 100q - q^2\), \(C = 20q + 300\). Тогда \(100 - 2q = 20\), \(q = 40\), прибыль \(\Pi(40) = 1300\). \(\Pi'' = -2 < 0\) — максимум.

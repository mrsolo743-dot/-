# Математика по шагам

Сайт для изучения высшей математики (вуз) так, будто рядом преподаватель. Основной упор — на **математическое направление** (строгие определения и доказательства), с приложениями для **технических** специальностей и минимальной **экономической** базой. Метки «Математика / Техника / Экономика» на главной и в темах показывают, что кому нужно; на главной есть фильтр по направлению.

В каждой теме есть:

- **теория с выводом формул по шагам**: видно, откуда что взялось;
- **блоки «Почему так?»**, которые раскрываются, если шаг непонятен;
- **интерактивный график**: двигаешь ползунки и видишь, как меняется функция;
- **тренажёр**: задачи генерируются случайно, ответ проверяется автоматически, есть подсказка и пошаговое решение.

Готовые темы:

- **Логика, кванторы и доказательства** (`topics/logic.html`) — фундамент, с него стоит начинать: высказывания и таблицы истинности (лаборатория с проверкой равносильности и контрпримером), законы логики, кванторы и почему важен их порядок, построение отрицания любого определения по шагам (предел, непрерывность, sup, инъективность…), методы доказательства (контрапозиция, от противного, индукция, контрпример). Тренажёр: «постройте отрицание» с объяснением каждой типичной ошибки, «равносильны ли формулы», «верно или неверно».
- **Множества и отображения** (`topics/sets.html`): операции и связь с логикой (доказательство «возьмём элемент»), лаборатория с диаграммой Венна и проверкой равенства множеств, образ и прообраз, инъекции/сюръекции/биекции (и почему важно «откуда и куда»), мощность: счётность ℤ и ℚ (таблица с обходом по диагоналям), интерактивная диагональ Кантора, теоремы Кантора и Кантора — Бернштейна. Тренажёр: закрасить область кликами, равны ли множества, тип отображения по стрелочной диаграмме, функции на ℝ, счётно или нет.
- **Вещественные числа** (`topics/reals.html`): дыры в ℚ, аксиома полноты, sup и inf (интерактивная числовая прямая: зона верхних границ и ε-свидетель из рабочего определения sup), теорема о существовании sup по шагам, принцип Архимеда, плотность ℚ, существование √2, вложенные отрезки. Тренажёр: sup/inf множеств (с вопросом, достигаются ли они) и lim sup/lim inf последовательностей.
- **Пределы** (`topics/limits.html`): ε–N и ε–δ в интерактиве (видно, как N зависит от ε и почему у (−1)ⁿ предела нет), доказательства по определению по шагам, отрицание определения, частичные пределы, lim sup и lim inf (график «огибающих хвостов» sup/inf, теорема lim ⇔ lim sup = lim inf), теоремы с доказательствами (единственность, ε/2, два милиционера, Вейерштрасс, Больцано — Вейерштрасс, критерий Коши), замечательные пределы, эквивалентности, приложения. Тренажёр: 5 режимов вычисления пределов с решением и численной проверкой + режим «найдите N(ε)».
- **Производная** (`topics/derivative.html`): от секущей к касательной (интерактивно), вывод таблицы производных и правил, лаборатория «продифференцируй любую функцию» с решением по шагам и графиками f и f′, тренажёр на 4 уровня с распознаванием типичных ошибок; теоремы Ферма, Ролля, Лагранжа, Коши и правило Лопиталя с доказательствами; приложения (линеаризация, погрешности, метод Ньютона, предельные издержки, эластичность).
- **Квадратные уравнения** (`topics/quadratic.html`): повторение школьной базы.

## Как открыть

Это обычный статический сайт, сервер и сборка не нужны.

```bash
python3 -m http.server 8000   # или: npm start
# открыть http://localhost:8000
```

Можно и просто открыть `index.html` в браузере.

## Тесты

```bash
npm test
```

Проверяется, что:

- разбор формул понимает привычную запись (`2x sin x`, `sin^2 x`, `e^-x`, русская «х») и сообщает об ошибках по-русски;
- производные совпадают с численными во всех сгенерированных задачах, а упрощение не меняет значение;
- верный ответ в любой форме засчитывается, а типичные ошибки (забыли u' в сложной функции, (uv)' = u'v' и т. п.) распознаются;
- ответы всех шаблонов пределов совпадают с численным приближением, а найденное N(ε) действительно работает и минимально;
- разбор логических формул, таблицы истинности и равносильность верны; отрицание каждого определения строится по шагам, у варианта ответа ровно один правильный, у каждого неверного — объяснение;
- sup/inf совпадают с численной оценкой по выборке элементов (и достижимость — тоже), lim sup/lim inf — с sup/inf далёких хвостов;
- равенства множеств совпадают с равносильностью соответствующих логических формул; конечные отображения классифицируются верно; число из диагонали Кантора отличается от каждого в списке;
- задачи по квадратным уравнениям и проверка их ответов работают корректно.

## План развития

Приоритет — математическое направление; техника — приложения и вычисления; экономика — только база.

1. ✅ Шаблон темы: теория → вывод по шагам → интерактивный график → тренажёр.
2. ✅ **Производная** и математический движок (разбор формул, символьное дифференцирование).
3. ✅ **Пределы** со строгими определениями и доказательствами; фильтр направлений на главной.
4. ✅ **Логика, кванторы и доказательства** — фундамент: отрицания, индукция, от противного, тренажёр.
5. ✅ **Вещественные числа**: sup/inf, аксиома полноты; lim sup и lim inf в «Пределах».
6. ✅ **Множества и отображения**: операции, инъекции/сюръекции/биекции, мощность, несчётность ℝ (диагональ Кантора).
7. **Непрерывность** и **формула Тейлора** (с графиком приближения многочленами).
8. **Исследование функции**, **интеграл**, **ряды**.
9. **Линейная алгебра**: определители, метод Гаусса по шагам, линейные пространства.
10. **ИИ-помощник** «спроси преподавателя»: чат, который знает текущую задачу и шаги решения (нужен небольшой сервер, например Cloudflare Workers / Vercel, чтобы ключ API не попал в код страницы).
11. **Публикация**: GitHub Pages (Settings → Pages → ветка `main`, папка `/`).

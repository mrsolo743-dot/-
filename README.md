# Математика по шагам

Сайт для изучения тем по математике так, будто рядом учитель. В каждой теме есть:

- **теория с выводом формул по шагам**: видно, откуда что взялось;
- **блоки «Почему так?»**, которые раскрываются, если шаг непонятен;
- **интерактивный график**: двигаешь ползунки и видишь, как меняется функция;
- **тренажёр**: задачи генерируются случайно, ответ проверяется автоматически, есть подсказка и пошаговое решение.

Сейчас готова первая тема: **«Квадратные уравнения»** (`topics/quadratic.html`).

## Как открыть

Это обычный статический сайт, сервер и сборка не нужны.

```bash
python3 -m http.server 8000   # или: npm start
# открыть http://localhost:8000
```

Можно и просто открыть `index.html` в браузере.

## Структура

```
index.html                  — главная со списком тем
topics/quadratic.html       — тема «Квадратные уравнения»
assets/style.css            — общий дизайн (есть тёмная тема и мобильная вёрстка)
assets/js/plot.js           — построитель графиков на canvas (без библиотек)
assets/js/math-render.js    — отрисовка формул через KaTeX
assets/js/quadratic-core.js — генерация задач, решение по шагам, проверка ответа
assets/js/quadratic.js      — интерфейс страницы темы
vendor/katex/               — KaTeX, лежит локально, интернет для формул не нужен
tests/                      — тесты логики (npm test)
```

## Тесты

```bash
npm test
```

Проверяется, что генератор задач на всех уровнях даёт правильные корни, что пошаговые решения не содержат ошибок и что проверка ответа понимает разные форматы ввода: `2; -3`, `x1=2; x2=-3`, `3/2`, `1,5`, `нет`.

## План развития

1. ✅ **Прототип одной темы**: квадратные уравнения (теория, вывод формулы, график, тренажёр).
2. **Шаблон темы**: вынести общую структуру (теория → график → тренажёр), чтобы новая тема добавлялась быстро.
3. **Новые темы**: линейная функция, системы уравнений, тригонометрия, производная, логарифмы.
4. **ИИ-помощник**: чат «спроси учителя», который знает, какую задачу сейчас решает ученик. Для него нужен небольшой сервер (например, Cloudflare Workers или Vercel), чтобы ключ API не попал в код страницы.
5. **Прогресс**: пройденные темы, статистика ошибок; позже, при необходимости, вход и база данных.
6. **Публикация**: GitHub Pages (Settings → Pages → ветка `main`, папка `/`).

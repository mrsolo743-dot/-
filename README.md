# Математика по шагам

Сайт для изучения высшей математики (вуз) так, будто рядом преподаватель. В каждой теме есть:

- **теория с выводом формул по шагам**: видно, откуда что взялось;
- **блоки «Почему так?»**, которые раскрываются, если шаг непонятен;
- **интерактивный график**: двигаешь ползунки и видишь, как меняется функция;
- **тренажёр**: задачи генерируются случайно, ответ проверяется автоматически, есть подсказка и пошаговое решение.

Готовые темы:

- **Производная** (`topics/derivative.html`): от секущей к касательной (интерактивно), вывод таблицы производных и правил, лаборатория «продифференцируй любую функцию» с решением по шагам и графиками f и f′, тренажёр на 4 уровня с распознаванием типичных ошибок.
- **Квадратные уравнения** (`topics/quadratic.html`): повторение школьной базы.

## Как открыть

Это обычный статический сайт, сервер и сборка не нужны.

```bash
python3 -m http.server 8000   # или: npm start
# открыть http://localhost:8000
```

Можно и просто открыть `index.html` в браузере.

## Структура

```
index.html                  — главная со списком тем
topics/derivative.html      — тема «Производная»
topics/quadratic.html       — тема «Квадратные уравнения»
assets/style.css            — общий дизайн (есть тёмная тема и мобильная вёрстка)
assets/js/plot.js           — построитель графиков на canvas (без библиотек)
assets/js/math-render.js    — отрисовка формул через KaTeX
assets/js/steps.js          — пошаговое раскрытие выводов (<ol class="steps" data-reveal>)
assets/js/expr.js           — математический движок: разбор формул, упрощение,
                              TeX, дифференцирование с пошаговым объяснением
assets/js/derivative-core.js — задачи по производным, проверка ответа, типичные ошибки
assets/js/derivative.js     — интерфейс темы «Производная»
assets/js/quadratic-core.js — задачи по квадратным уравнениям
assets/js/quadratic.js      — интерфейс темы «Квадратные уравнения»
vendor/katex/               — KaTeX, лежит локально, интернет для формул не нужен
tests/                      — тесты логики (npm test)
```

## Тесты

```bash
npm test
```

Проверяется, что:

- разбор формул понимает привычную запись (`2x sin x`, `sin^2 x`, `e^-x`, русская «х») и сообщает об ошибках по-русски;
- производные совпадают с численными во всех сгенерированных задачах, а упрощение не меняет значение;
- верный ответ в любой форме засчитывается, а типичные ошибки (забыли u' в сложной функции, (uv)' = u'v' и т. п.) распознаются;
- задачи по квадратным уравнениям и проверка их ответов работают корректно.

## План развития (вузовская программа)

1. ✅ Прототип и шаблон темы: теория → вывод по шагам → интерактивный график → тренажёр.
2. ✅ **Производная** и математический движок (разбор формул, символьное дифференцирование).
3. **Пределы**: замечательные пределы, эквивалентности, раскрытие неопределённостей по шагам.
4. **Исследование функции**: экстремумы, выпуклость, асимптоты — на том же движке.
5. **Интегралы**: таблица, замена, по частям; площадь под графиком.
6. **Линейная алгебра**: матрицы, определители, метод Гаусса по шагам.
7. **ИИ-помощник** «спроси преподавателя»: чат, который знает текущую задачу и шаги решения. Нужен небольшой сервер (Cloudflare Workers / Vercel), чтобы ключ API не попал в код страницы.
8. **Прогресс**: статистика по темам и типичным ошибкам.
9. **Публикация**: GitHub Pages (Settings → Pages → ветка `main`, папка `/`).
